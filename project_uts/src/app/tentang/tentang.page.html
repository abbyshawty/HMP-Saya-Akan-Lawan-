Tentang Aplikasi

SIMOBILE

Prototipe aplikasi kasir mobile untuk warung Toko Makmur Jaya. Pemilik warung bisa melihat ringkasan penjualan, mencari dan mengelola barang, lalu mencatat transaksi dari ponsel.

Dibuat dengan Ionic Angular untuk UTS mata kuliah Hybrid Mobile Programming, Universitas Surabaya. Data hanya disimpan di dalam aplikasi dan kembali ke data awal saat aplikasi dibuka ulang.
